# QUBLITZ 2026

This repository contains two challenge projects:

- [Quantum Minesweeper](quantum_minesweeper/): quantum error correction, IQM hardware results, and presentation materials.
- [Magic State Verification](magic_state_verification/): the Theory / Algorithms challenge.
- [Quantum Circuit Golf](prism_quantum_circuit_golf/): quantum circuit golf challenge, quantum circuit optimizer designed to reduce gate costs and circuit depth while preserving functionality.
- [Schrödinger's Home](schrodingers-home/): quantum create challenge: a 2D pixel-art quantum escape-room game built around an eight-qubit state-vector simulator, quantum measurement, interference, and musical puzzles.

Each project has its own README and setup instructions.
