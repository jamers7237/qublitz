# PRISM — live demonstration storyboard (3–5 minutes)

## 1. The hook (20 seconds)

"Most people see a list of gates. Our optimizer sees which *parities of the
original qubits* each phase gate acts upon. Two distant phase gates may cancel
even after CNOT networks scramble the wires."

## 2. Mathematical proof on one slide (35 seconds)

Show the `L3-parity-gauntlet-49-to-1` experiment (generated by
`run_experiments.py`). This 49-gate 4-qubit circuit reduces to a *single T*.
Trace the conserved q1 parity across a nontrivial CNOT network repeated four
times. Its affine transformation has order four; phase terms combine mod 8.
Use `L3-parity-echo` from `experiments/circuits.json` to introduce the simpler idea.

## 3. General method (45 seconds)

Three passes: parity phase collection, exact bounded local synthesis, GF(2)
affine synthesis. Point out whole-circuit weighted candidate selection.

## 4. Live correctness (40 seconds)

```bash
python -m unittest discover -s tests -v
python run_experiments.py
```

Show the report and a selected before/after JSON example. Emphasize the
independent full-unitary test *up to global phase*.

## 5. Limitations and insight (40 seconds)

Show honest failure cases: H-crossing transformations, windows requiring more
than the synthesis bound, and cases where two-qubit-gate savings are impossible
without changing a parity network. Explain how experiments guide improvements.

## 6. Hardware extension (optional, only with access)

Show IQM/Qiskit *transpiled-native* gate counts for the same input before and
after, then only if token/time quota permits submit and compare noisy counts.

## Judges might ask

- **Why equivalent?** The phase-polynomial algebra tracks affine Boolean
  functions; all local replacements are verified by 2x2/4x4 matrices; final
  output is checked with an independent full `2^n x 2^n` unitary.
- **Why not optimize just the gate count?** The supplied cost weights change.
- **Is this brand-new theory?** No. Phase polynomials are known; the creative
  contribution is this specific lightweight, cost-aware hybrid architecture.
- **How do you handle worst cases?** Return the valid original rather than a
  more expensive or nonequivalent circuit.
- **What comes next?** Larger parity-network synthesis, scheduling optimized
  across H barriers, and formal exact certificates.
