Empirical frequencies fluctuate around theory, as finite samples should. We never claim finite-sample equality.

## Reproducing

```bash
npm run experiments              # default: 20000 shots, seed 2025
npm run experiments -- 100000 7  # custom shots and seed
python scripts/qiskit_reference.py   # optional; needs qiskit (e.g. ../myenv/bin/python)
npm test
npm run smoke                    # needs Google Chrome installed (or set CHROME_PATH)
```

In the game, **Notebook → Draft Score → Export experiment log (JSON)** exports a player's real session log (anonymised: no name). The debug overlay (`?debug=1` → quantum tab) shows the Born probabilities next to the player's observed frequencies, and offers a separate, **unlogged** 4000-shot simulation.
