# Photos

Drop real photos here. They are only shown when the player clicks the matching frame or paper in the game.

- `james.jpg`: right-bedroom portrait (the "RR = third" clue is drawn over it automatically)
- `dorm.jpg`: left-bedroom move-in photo
- `clipping.png`, `poster.png`, `projector.jpg`, `sticky.png`: papers and props

Missing files show a designed placeholder. Configure paths and captions in `src/data/photos.ts`. See `ART_REPLACEMENT_GUIDE.md`.
